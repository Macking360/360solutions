# 360 Solutions

Next.js 15 app for 360 Solutions Group, deployed on Vercel.

## Products

- `/` — 360 Solutions home (product studio)
- `/products/tls-guard` — TLS Guard product page
- `/demo-kit` — Demo Kit request page
- `/bc-multiplex` — BC Multiplex (in development — see `_static-backup/` for the original static site)

## Development

```bash
npm install
npm run dev
```

See `DEPLOYMENT.md` for Vercel setup and environment variables.
